Codex CLI で作業していたら、急に上限に達して止まった。5時間の枠なのか、週間の枠なのか、いつ戻るのかが分からない。そんなときに今の残りとリセット時刻を確かめる方法を、公式ドキュメントとソースコードで確認できた範囲で整理しました。

:::message alert
Codex の使用量制限は、ここ数か月だけでも何度か変更されています。この記事は2026年10月16日時点の公式ドキュメントと openai/codex のソースをもとにしています。数値や仕様は変わる可能性があるので、最終的には公式の使用量ダッシュボードで確認してください。
:::

## 先に結論

| やりたいこと | 方法 |
|---|---|
| ターミナルで今の残りとリセット時刻を見たい | Codex CLI の `/status` |
| ブラウザで見たい | ChatGPT の Codex 使用量ダッシュボード |
| 作業中ずっと残りを表示しておきたい | Codex CLI の `/statusline` |
| 日別にどれだけ使ったかを振り返りたい | ccusage（OSS）の `codex` レポート |
| ターミナルを離れているとき、複数アカウントや他サービスとまとめて見たい | スマートフォンのウィジェット（最後に紹介） |

## 前提：Codex の上限はプランで違う

ChatGPT のプランで Codex を使う場合、公式の料金ページには次のように書かれています（2026年10月16日時点）。

- **Plus と Business（Standard）**：5時間あたりの上限があります。使えるメッセージ数は、モデルやタスクの大きさ・複雑さによって変わります。
- **Pro**：「現在、5時間の上限はない」とされています。
- **週間の上限**：「週間の上限が適用される場合もある」とされています。
- ローカルでのメッセージとクラウドタスクは同じ使用枠を消費し、クラウドタスクのほうが枠を多く使うことがあります。

つまり「5時間枠にはまだ余裕があるはずなのに止まった」という場合は、週間の上限に当たっている可能性があります。逆に Pro なら、気にするのは主に週間の上限です。

リセットの周期について、料金ページは具体的な時刻を書いておらず、「現在の上限とリセット時刻は使用量ダッシュボードで確認してください」としています。以下の方法で、自分のアカウントの実際の値を見るのが確実です。

## 方法1：Codex CLI の `/status`（公式・無料）

Codex CLI のセッション内で次のように入力します。

```text
/status
```

公式のコマンドリファレンスでは「チャット ID、コンテキストの使用量、レート制限を表示する」と説明されています。openai/codex のソースにあるテスト用のスナップショットを見ると、表示はおおむね次のような形です。

```text
  Context window:  100% left (2.2K used / 272K)
  5h limit:        [███████████░░░░░░░░░] 55% left (resets 09:25)
  Weekly limit:    [██████████████░░░░░░] 70% left (resets 09:55)
  Credits:         Available
```

- `5h limit`：5時間枠の残り（%）と、次にリセットされる時刻
- `Weekly limit`：週間枠の残り（%）とリセット時刻
- `Credits`：追加のクレジットの状況

上の表示はソース内のテストデータなので、行の有無や数値は自分のプランや時期によって変わります。たとえば5時間の上限がないプランでは、その行は出ないと考えてください。起動直後などでデータがまだ取れていないときは `Limits: data not available yet` のように表示されます。

`/status` の画面の上部には、最新の情報は `https://chatgpt.com/settings/usage` を見るように、という案内も表示されます。

表示されない、項目が少ないという場合は、CLI が古い可能性があります。インストールした方法に合わせて更新してください。

```bash
# npm でインストールした場合
npm install -g @openai/codex@latest
```

## 方法2：ChatGPT の使用量ダッシュボード（公式・無料）

ブラウザで次のページを開くと、現在の上限とリセット時刻を確認できます。

https://chatgpt.com/codex/settings/usage

Codex CLI を開いていないときや、CLI・IDE 拡張・Web の Codex をまたいで全体の残りを見たいときに便利です。公式の料金ページも、上限に余裕があるかを把握するために1〜2週間ごとにダッシュボードを見ることを勧めています。

なお、CLI には `/usage` というコマンドもあり、公式リファレンスでは「ChatGPT でサインインしている場合、使用量と請求の設定を開く」と説明されています。

## 方法3：`/statusline` で常に表示しておく

Codex CLI は画面下部のステータスラインに表示する項目を選べます。

```text
/statusline
```

openai/codex のソースを見ると、選べる項目の中に5時間枠の残り（Remaining usage on the primary usage limit）と週間枠の残り（Remaining usage on the secondary usage limit）が含まれています。どちらも「データが取れないときは省略される」設計です。作業中ずっと残りが目に入るので、長いタスクの途中で急に止まる事態を減らせます。

## 方法4：ccusage で使い方を振り返る（オープンソース・無料）

[ccusage](https://github.com/ryoppippi/ccusage) は、コーディングエージェントの CLI が手元のマシンに保存している使用ログを集計するツールです。Claude Code 向けとして知られていますが、現在は Codex にも対応しています。

```bash
# Codex の使用量を日別に表示
npx ccusage@latest codex daily
```

README によると、`daily` のほかに `weekly`、`monthly`、`session` の単位でもレポートを出せます。

注意点が2つあります。

- 集計しているのは**手元のログ**なので、ほかのマシンや Web 版の Codex での利用は含まれません。
- 表示されるのはトークン数などの集計で、**公式の5時間枠・週間枠の残り（%）とは別物**です。「あと何%残っているか」は方法1〜3で確認してください。

## 上限に達したときの選択肢

公式の料金ページに書かれている内容をまとめると、次のとおりです。

- 実行中のターンの途中で上限に達した場合、そのターンはエージェントが作業を続けられる（作業途中で切られにくい）。
- Plus と Pro は、プランを変えずに追加のクレジットを購入して作業を続けられる。
- API キーを使えば、標準の API 料金でローカルの作業を追加で行える。
- それ以外は、ダッシュボードや `/status` に出ているリセット時刻まで待つ。

また、高速モードや画像を含むやり取りは、通常より速く枠を消費すると説明されています。残りが少ないときは意識しておくとよいでしょう。

## 比較

| 方法 | わかること | 公式の残り（%） | 見る場所 | 料金 |
|---|---|---|---|---|
| `/status` | 5時間枠・週間枠の残り、リセット時刻、クレジット | ○ | ターミナル | 無料 |
| 使用量ダッシュボード | 現在の上限とリセット時刻 | ○ | ブラウザ | 無料 |
| `/statusline` | 5時間枠・週間枠の残りを常時表示 | ○ | ターミナル | 無料 |
| ccusage | 日別・週別などの使用量の集計 | ×（集計のみ） | ターミナル | 無料（OSS） |

## 使い分け

- ターミナルで作業していて、たまに確認できればいい → `/status`。
- 長いタスクを回すことが多い → `/statusline` に5時間枠・週間枠を出しておく。
- どの日にどれだけ使ったか振り返りたい → ccusage。
- ターミナルを離れているとき（移動中、会議中、寝る前に翌朝のリセット時刻だけ見たいとき）や、仕事用と個人用など複数アカウント、Claude・Copilot・Gemini も併用している → スマートフォンで見られるものがあると便利です。このケースのために筆者が作ったのが次のアプリです。

## 最後に：筆者のアプリ UsageNow について

※ここからは筆者が開発したアプリの紹介です。

UsageNow は、各 AI プランの残りとリセット時刻を iPhone のホーム画面に表示するアプリです。

- **対応する上限**：ChatGPT Codex の5時間枠と週間枠、Claude の5時間セッション上限と週間上限（モデル別の週間上限も含む）、GitHub Copilot のプレミアムリクエスト・チャット・コード補完、Gemini のモデルごとの1日あたりのリクエスト上限
- **カウントダウン**：リセットまでのカウントダウンと、正確なリセット時刻を地域の表記で表示
- **アラート**：5時間上限・週間上限・すべての上限から選び、90 や 98 など好きなパーセンテージを入力。上限ごと・サイクルごとに1回だけ届きます。上限が戻った瞬間を知らせるリセットアラートも
- **複数アカウント**：仕事用と個人用などを並べて表示。5時間リセットが近い順、週間リセットが近い順などで並べ替え
- **ウィジェット**：ホーム画面・ロック画面の全サイズ。ウィジェット上で全アカウントをめくれて、タップで更新。Apple Watch のコンプリケーションにも対応
- **対応端末**：iPhone、iPad、Apple Watch

サインインは各サービス公式のログインページで行い、サインイン情報はデバイスのキーチェーンに保存されます。UsageNow のサーバはなく、アプリが通信するのは各サービスだけで、アカウント登録もトラッキングもありません。

https://apps.apple.com/jp/app/id6818607603?pt=118326163&ct=bm_usagenow_jp_zenn&mt=8

UsageNow は独立した個人開発アプリで、Anthropic、OpenAI、GitHub、Microsoft、Google とは提携していません。Claude、ChatGPT、Codex、GitHub Copilot、Gemini は各所有者の商標です。

ターミナルにいる間は `/status` と `/statusline` で十分です。手元を離れたときにだけ必要になる道具として、選択肢の一つにしてもらえたらうれしいです。
