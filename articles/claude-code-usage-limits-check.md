Claude Code で長めのタスクを走らせていたら途中で止まった。5時間枠はまだ余裕があると思っていたのに、実は週間上限のほうが先に来ていた。そうならないように、今どれくらい使っていて、いつリセットされるのかを確認する方法を整理しました。

## 先に結論

| やりたいこと | 方法 |
|---|---|
| ターミナルで今の残りを見たい | Claude Code の `/usage` |
| ブラウザで見たい | claude.ai の設定 → 使用量 |
| 使い方を日別・5時間ブロック別に振り返りたい | ccusage（OSS） |
| 今のペースでいつ枠を使い切るか予測したい | Claude Code Usage Monitor（OSS） |
| 作業中ずっと目に入るところに出したい | ステータスライン |
| ターミナルを離れているとき、複数アカウントや他サービスとまとめて見たい | スマートフォンのウィジェット（最後に紹介） |

## 前提：上限は2種類ある

Claude の Pro／Max プランには、主に次の2つの上限があります。

- **5時間のセッション上限**：一定時間ごとにリセットされる枠
- **週間上限**：週単位でリセットされる枠（プランによってはモデル別の週間上限もあります）

Claude Code と claude.ai は同じプランの上限を共有しています。具体的な上限量はプランや時期によって変わり、公式の画面ではトークン数ではなく使用率（%）とリセット時刻で表示されます。最新の仕様は Anthropic のヘルプセンターで確認してください。

「5時間枠には余裕があるのに止まった」という場合、たいていは週間上限か、モデル別の週間上限に当たっています。

## 方法1：Claude Code の `/usage`（公式・無料）

Claude Code のセッション内で次のように入力します。

```text
/usage
```

現在のセッション（5時間枠）と今週の使用率、それぞれのリセット時刻が表示されます。ターミナルにいるなら、まずはこれで十分です。

表示されない場合は Claude Code が古い可能性があります。

```bash
claude update
```

## 方法2：claude.ai の設定画面（公式・無料）

ブラウザで claude.ai を開き、設定 → 使用量 を開くと、同じプランの使用状況とリセット時刻を確認できます。Claude Code を開いていないときや、claude.ai とどちらでどれだけ使ったかを気にせず全体の残りを見たいときに便利です。

## 方法3：ccusage（オープンソース・無料）

[ccusage](https://github.com/ryoppippi/ccusage) は、Claude Code が手元のマシンに保存している使用ログを集計する CLI です。インストールせずに `npx` で実行できます。

```bash
# 日別レポート
npx ccusage@latest

# 5時間ブロック単位で集計
npx ccusage@latest blocks
```

日別・月別・セッション別・5時間ブロック別に、トークン数と API 料金に換算した推定コストを見られます。どのプロジェクトやどの日に使いすぎたかを振り返るのに向いています。

注意点が2つあります。

- 集計しているのは**手元のログ**なので、ほかのマシンや claude.ai での利用は含まれません。
- 表示されるのはトークン数と推定値で、**公式画面の使用率（%）とは別物**です。「あと何%残っているか」は方法1・2で確認してください。

## 方法4：Claude Code Usage Monitor（オープンソース・無料）

[Claude Code Usage Monitor](https://github.com/Maciek-roboblog/Claude-Code-Usage-Monitor) は、ターミナルに常駐してトークンの消費ペースを表示し、今のペースで続けるとセッションがいつ尽きそうかを予測してくれる Python 製のツールです。

```bash
uv tool install claude-monitor
claude-monitor --plan max5
```

`--plan` には自分のプラン（`pro`、`max5`、`max20`、`team`、`custom`）を指定します。長いタスクを始める前に「この枠で最後まで行けそうか」を見積もるのに向いています。こちらも手元のログをもとにした推定です。

## 方法5：ステータスラインに出しておく

Claude Code は画面下部のステータスラインをカスタマイズできます。`/statusline` と入力すると設定を手伝ってくれます。ccusage にはステータスライン用のコマンド（`ccusage statusline`、執筆時点ではベータ）もあるので、組み合わせると作業中ずっと消費状況が目に入ります。

## 比較

| 方法 | わかること | 公式の使用率 | 見る場所 | 料金 |
|---|---|---|---|---|
| `/usage` | セッション・週間の使用率、リセット時刻 | ○ | ターミナル | 無料 |
| claude.ai 設定 | 同上 | ○ | ブラウザ | 無料 |
| ccusage | トークン数、推定コスト、5時間ブロック | 推定 | ターミナル | 無料（OSS） |
| Claude Code Usage Monitor | 消費ペースと枯渇予測 | 推定 | ターミナル | 無料（OSS） |
| ステータスライン | 常時表示（中身は組み合わせ次第） | 組み合わせ次第 | ターミナル | 無料 |

## 使い分け

- 1つのアカウントで、作業はほぼターミナル → `/usage` で十分です。
- 使い方を振り返りたい、どこで使いすぎたか知りたい → ccusage。
- 長いタスクの前に、最後まで持つか見積もりたい → Claude Code Usage Monitor。
- ターミナルを離れているとき（移動中、会議中、寝る前に翌朝のリセット時刻だけ見たいとき）や、仕事用と個人用など複数アカウント、Codex・Copilot・Gemini も併用している → スマートフォンで見られるものがあると便利です。最後のケースのために筆者が作ったのが次のアプリです。

## 最後に：筆者のアプリ UsageNow について

※ここからは筆者が開発したアプリの紹介です。

UsageNow は、各 AI プランの残りとリセット時刻を iPhone のホーム画面に表示するアプリです。

- **対応する上限**：Claude の5時間セッション上限と週間上限（モデル別の週間上限も含む）、ChatGPT Codex の5時間枠と週間枠、GitHub Copilot のプレミアムリクエスト・チャット・コード補完、Gemini のモデルごとの1日あたりのリクエスト上限
- **カウントダウン**：リセットまでのカウントダウンと、正確なリセット時刻を地域の表記で表示
- **アラート**：5時間上限・週間上限・すべての上限から選び、90 や 98 など好きなパーセンテージを入力。上限ごと・サイクルごとに1回だけ届きます。上限が戻った瞬間を知らせるリセットアラートも
- **複数アカウント**：仕事用と個人用、Pro と Max を並べて表示。5時間リセットが近い順、週間リセットが近い順などで並べ替え
- **ウィジェット**：ホーム画面・ロック画面の全サイズ。ウィジェット上で全アカウントをめくれて、タップで更新。Apple Watch のコンプリケーションにも対応
- **対応端末**：iPhone、iPad、Apple Watch
- **言語**：50言語に対応、アプリの設定からいつでも切り替え可能

アカウントへのサインインが必要なアプリなので、その扱いを明記しておきます。サインインは各サービス公式のログインページで行い、サインイン情報はデバイスのキーチェーンに保存されます。UsageNow のサーバはなく、アプリが通信するのは各サービス（と購入のための Apple）だけで、アカウント登録もトラッキングもありません。
アプリ内で24時間の無料トライアルを開始すると、ウィジェットを含むすべての機能を使えます。その後も使う場合は買い切りで、サブスクリプションはありません。

https://apps.apple.com/jp/app/id6818607603?pt=118326163&ct=usagenow_zenn&mt=8

UsageNow は独立した個人開発アプリで、Anthropic、OpenAI、GitHub、Microsoft、Google とは提携していません。Claude、ChatGPT、Codex、GitHub Copilot、Gemini は各所有者の商標です。

ターミナルにいる間は `/usage` や ccusage で足ります。手元を離れたときにだけ必要になる道具として、選択肢の一つにしてもらえたらうれしいです。
